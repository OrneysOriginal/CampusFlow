# CampusFlow — практическая работа №2

Проект каталога событий с точной геометрией контейнера, адаптивной Grid/Flex-сеткой, систематизированными интервалами и четырьмя стресс-тестами текста. Подробный отчёт: [docs/practical-02.md](docs/practical-02.md).

## Обычный запуск (Node.js 20.19+ / 22.12+)

```bash
npm ci
npm run dev
```

Откройте адрес Vite из терминала (обычно `http://localhost:5173/`). Основные страницы: `#/events`, `#/events/semantic-html`, `#/register/semantic-html`.

## Запуск без npm (автономная версия)

В каталоге `offline/` заранее собраны HTML/CSS/JS без зависимостей. Можно открыть `offline/index.html` прямо в браузере или раздать его через:

```bash
python -m http.server 8000 --directory offline
```

Адрес: `http://localhost:8000/`.

Чтобы обновить автономную версию после правки исходников, выполните `python build_offline.py`.

## Проверка

```bash
npm run lint
npm run format:check
npm run build
npm run check
```

Для проверки длинного контента откройте `?stress=title#/events`, `?stress=organization#/events`, `?stress=url#/events` и `?stress=empty#/events`. Например: `http://localhost:5173/?stress=url#/events`.

Проверяйте геометрию при 1440 × 900, 1152 × 900, 375 × 812, zoom 100%; отсутствие горизонтальной прокрутки; переключение фильтров, открытие мероприятия, регистрацию и ошибки формы. Это тестовые viewport, **а не измеренный оригинальный макет**.

**Макет получен:** три PDF-страницы CampusFlow. Контрольный размер выбран 1080 × 768. Финальный пользовательский отчёт Playwright подтвердил **22/22 выбранных элементов** с отклонением ≤5 px; координаты PDF оценочные. Детали: [`docs/practical-02.md`](docs/practical-02.md).

## Автоматическое сравнение с PDF-макетом

```bash
npm install
npx playwright install chromium
npm run test:visual
```

Команда самостоятельно запускает Vite на `127.0.0.1:4178`, проверяет каталог, страницу мероприятия и форму при **1080 × 768** и создаёт `visual-results/report.html`, `report.json`, фактические скриншоты и карты различий (`*-diff.png`). Откройте `visual-results/report.html` в браузере.

Макеты для сравнения: `tests/visual/reference/*.png` (три страницы предоставленного PDF). Контрольные координаты: `tests/visual/geometry-reference.json`, **ориентировочно считанные из PDF**, а не полученные из Figma. Красные пиксели карты разницы показывают отличие цветов более 25/255 и чувствительны к сглаживанию текста. Для допуска **3–5 px** используйте столбец `Max Δ` у каждого элемента, а не общий процент различия изображения. Скрипт сохраняет отчёт даже при несоответствии макету; критическая ошибка выполнения возвращает ненулевой код.

**Установка:** если до этого использовался `npm ci`, после добавления Playwright один раз выполните `npm install` (обновит `package-lock.json`). Затем `npm ci` снова будет доступен.
